## Custom Footer для Quartz

[🇬🇧 English](README.md) · [🇷🇺 Русский](README.ru.md)

Настраиваемый компонент футера для [Quartz](https://quartz.jzhao.xyz/).

## Возможности

- Макет: текст копирайта слева и настраиваемые ссылки справа.
- Адаптивная верстка: на узких экранах элементы футера располагаются вертикально и выравниваются по центру.
- Настраиваемый текст после символа копирайта и года.
- Автоматически используется текущий год; ручное обновление каждый год не требуется.
- Поддерживаются именованные ссылки, настроенные в `quartz.config.yaml`.
- Используется подход установки community-плагинов Quartz.

## Требования

- Рабочий проект Quartz.
- Версия Quartz, поддерживающая community-плагины с полями конфигурации `source`, `enabled` и `options`.

## Установка

Выполните команду из корневой папки проекта Quartz:

```bash
npx quartz plugin add github:semsig13-tech/custom-footer
```

Если в вашей версии Quartz используется другой порядок установки community-плагинов, следуйте документации для установленной версии.

## Настройка

Добавьте плагин в раздел `plugins` файла `quartz.config.yaml`:

```yaml
plugins:
  - source: github:semsig13-tech/custom-footer
    enabled: true
    options:
      copyrightText: "Name"
      copyright: true
      links:
        Website: https://www.name.org/
        GitHub: https://github.com/semsig13-tech/
```

Замените пример текста копирайта и ссылки на собственные значения. Соблюдайте отступы YAML.

### Пример с русским текстом

```yaml
plugins:
  - source: github:semsig13-tech/custom-footer
    enabled: true
    options:
      copyrightText: "Имя"
      copyright: true
      links:
        Сайт: https://www.name.org/
        ГитХаб: https://github.com/semsig13-tech/
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `copyrightText` | `string` | `""` | Текст, отображаемый после `©` и текущего года. Например, `Name`. |
| `copyright` | `boolean` | `true` | Значение `false` скрывает строку копирайта. |
| `links` | `Record<string, string>` | `{}` | Ссылки футера в формате `название: URL`. |

Год определяется с помощью `new Date().getFullYear()`. Например, в 2026 году будет показано `© 2026 Name`, а в 2027 году надпись автоматически изменится на `© 2027 Name`.

## Как изменить или скрыть копирайт

Измените значение `copyrightText`:

```yaml
options:
  copyrightText: "Название организации"
```

Чтобы скрыть копирайт, оставив ссылки видимыми, укажите:

```yaml
options:
  copyright: false
```

## Как добавить или изменить ссылки

Добавьте элементы в раздел `links`. Ключ — это отображаемое название ссылки, значение — адрес страницы:

```yaml
links:
  Документация: https://example.com/docs
  GitHub: https://github.com
```

Ссылки открываются в новой вкладке с атрибутом `rel="noopener noreferrer"`.

## Обновление плагина

Запустите команду обновления community-плагинов, поддерживаемую вашей версией Quartz, или удалите и добавьте плагин повторно с помощью CLI Quartz, если этот способ поддерживается вашей установкой. Проверьте документацию Quartz для команд, зависящих от версии: <https://quartz.jzhao.xyz/>.

## Решение проблем

- **Футер не отображается:** убедитесь, что запись находится в разделе `plugins`, параметр `enabled` равен `true`, а в разметке Quartz подключен компонент футера.
- **Текст или ссылки не меняются:** проверьте, что вы редактируете параметры именно этого плагина в нужном файле `quartz.config.yaml`, затем пересоберите или перезапустите сайт Quartz.
- **Ошибка YAML:** проверьте отступы и заключайте текст со специальными символами, например `:`, в кавычки.
